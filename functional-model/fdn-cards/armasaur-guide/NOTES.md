# Armasaur Guide — authoring notes

## Authoring background

"Whenever you attack with three or more creatures, put a +1/+1 counter
on target creature you control." Trigger condition "when you attack with
3+ creatures" requires an unbuilt trigger type (no 'attackersDeclared' or
count-conditional `on` value exists yet — see ENGINE_GAPS.md). Modeled
as a named trigger for manual scenario invocation until that gap closes.
