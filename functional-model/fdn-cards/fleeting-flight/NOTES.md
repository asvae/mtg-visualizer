# Fleeting Flight — authoring notes

## Authoring background

"Prevent all combat damage that would be dealt to it this turn" is a CR
614.2 replacement effect that the engine doesn't yet model. No mechanism
exists to prevent target-specific combat damage (see ENGINE_GAPS.md gap
#8). This effect is modeled as inert text only.

(Flagged during the 2026-09-18 comment-cleanup sweep: this gap is only
documented as prose/`describe` text, with no `missingSchemaFunctionality`
entry declaring it; worth a follow-up authoring pass, out of scope for a
comment-relocation-only sweep.)
