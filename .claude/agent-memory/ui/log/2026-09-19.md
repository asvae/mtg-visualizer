## Sinks page: `counters.test.ts` "corpus test" → "unit test" wording

`app/pages/app/engine/sinks/[[slug]].vue` still called `counters.test.ts`
a "corpus test" after `entry.ts`/`SINK_MODEL_DESIGN.md`/
`server/api/sink-catalog/index.get.ts` (schema agent) were already updated
to "unit test" for the 2026-09-19 rewrite (real compiled Forge cards, no
mocked `corpus.json` fixtures). The generic "Source — real evidence"
panel's "Corpus test" `EngineConsoleCodeSection` is shared by every sink
family though, and other families (`battlefield-presence.test.ts`,
`lifegain.test.ts`) genuinely still are corpus.json-backed — so the label
can't just become a blanket "Unit test". Used the existing `!queryResult`
check (already the discriminator for `CountersSink`'s query-less entries,
established right above in the same file) to make the label conditional:
`queryResult ? 'Corpus test' : 'Unit test'` (and matching
`not-found-label`). Updated the two stale doc comments referencing
`counters.test.ts` as a corpus test to match.
